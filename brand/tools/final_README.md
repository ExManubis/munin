# munin brand assets

The final logo is the 16 × 16 pixel raven with the Block wordmark, both drawn on the same pixel grid and shaded from above with a 1-bit dither. Open `index.html` for a visual overview.

## Files

```
svg/        mark, wordmark, lockup-horizontal, lockup-stacked
            *.svg uses currentColor · *-white.svg (#f4f4f4) · *-black.svg (#0a0a0a)
            solid/ holds the same shapes without the dither, for anything below 2×
png/        the same four shapes as pixel-exact PNGs at even scales (@2x–@32x),
            transparent white/black, plus padded -on-dark / -on-light @8x
favicon/    favicon.ico (16/32/48) · favicon.svg (solid, adapts to light/dark) · favicon-16/32/48.png
            apple-touch-icon.png (180) · android-chrome-192/512.png · maskable-512.png
            site.webmanifest · og-image.png · head.html (copy-paste <head> tags)
app-icon/   macos/AppIcon.icns + AppIcon.iconset/ + app-icon-macos-1024.png
            ios/app-icon-ios-1024.png (full-bleed and opaque; iOS applies the corner mask)
social/     og-image.png (1200×630) · og-image-tagline.png · github-social-preview.png (1280×640)
font/       Munin Block 0.1: OTF, TTF, WOFF2
```

## Colours

| Name  | Hex       | Use                                   |
|-------|-----------|---------------------------------------|
| Ink   | `#0a0a0a` | backgrounds, the mark on light        |
| Paper | `#f4f4f4` | the mark on dark, light backgrounds   |
| Dot   | `#1e1e1e` | dot-grid texture on icons and cards   |
| Rule  | `#4e4e4e` | viewfinder corners                    |

The logo is monochrome: always Ink or Paper, never a colour.

## Rules

- **The grid is the logo.** The mark is 16 × 11 units and the horizontal lockup is 59 × 11 units. Each unit is drawn as 2 × 2 sub-pixels with a Bayer dither: the top is solid and the lower rows thin out, as if lit from above. Scale PNGs by even numbers only (2×, 4×, 8×…) so every sub-pixel lands on whole pixels, and set `image-rendering: pixelated` when they're scaled in CSS. Use the SVGs for print and anywhere you need an arbitrary size.
- **Clear space:** keep at least 4 units (a quarter of the mark's width) clear on every side.
- **Minimum size:** the mark at 32 px wide, the horizontal lockup at 118 px wide (2× on screen). Below that the dither turns grey, so use the solid SVGs in `svg/solid/` or the favicon tiles. favicon-16, favicon-32 and favicon.svg are solid for the same reason.
- **The lockup is fixed:** a 5-unit gap; the i-dot is level with the crown, and the baseline is level with the throat. Don't rebuild it by hand.
- **Don't:** smooth or anti-alias the pixels, re-dither or change the shading, rotate or skew, outline, add other effects, mix the mark and wordmark at different scales, or set "munin" in another font.
- Wordmark only (no raven) is fine where the raven already appears nearby, for example in a nav bar next to the favicon.

## Website

Copy the files in `favicon/` to your web root and paste `favicon/head.html` into `<head>`.

## Regenerate

Everything here is generated by `brand/tools/export_final.py` from the master bitmaps (`PIXEL16` in `marks.py`, `BLOCK` in `pixvars.py`) and their tone maps (`TONE16` in `pixvars.py`, `word_tones` in `treat.py`). Edit those, then rerun the export and retake the overview screenshot:

```
cd brand/tools && .venv/bin/python export_final.py
./shot.sh "$PWD/../final/index.html" ../final/overview.png 1440 4180
```

Set `DITHER = False` in `export_final.py` to rebuild the solid kit.
