07LED

Dots on a dim matrix. The softest of the three, and it suits a glow, a pulse or a light-up sequence.

08SCANLINE

Every pixel row as a thin bar. It can draw itself in row by row, which makes a good save or write state.

10DITHER

Shaded from above with a 1-bit Bayer dither. On the wordmark the dither fades out toward the baseline, like a memory going soft.

Notes

For discussion
ONE BITMAPScanline, Dither and LED all render from the same 16 × 16 raven and Block lettering, so they line up pixel for pixel and can morph into each other.
MOTIONSuggested states: Recall for loading or search, Write for saving, and Fade for idle or offline. The light-up sequence at the top suits a launch screen or a site intro.
FONTMunin Block 0.1 is pixel-perfect at multiples of 16 px. It has no kerning or accented letters yet. Those are worth adding if it goes beyond headings and UI labels.
