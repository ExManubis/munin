# design

Exports of the issue tracker designs from the Paper file "munin", page "Issues v3". Each artboard has three files:

- `.png`: a 2× screenshot from Paper
- `.jsx`: Paper's JSX export with inline styles, wrapped in a component
- `.html`: the same markup as a standalone page you can open in a browser. Fonts load from Google Fonts.

The logo images point at the brand kit in `../brand/logo/treatments/` instead of Paper's asset host.
